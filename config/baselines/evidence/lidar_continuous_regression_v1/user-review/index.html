PR #72 — 직접 검토할 비교 자료

운영 설정 변경·새 추론·차량 제어 없이 기존 증거를 렌더링했습니다. 공통 경계·roll 기본값은 OFF입니다.

1. 지면 추정 실패 시 24점: 이전 평면으로 삭제 / 불명확해서 보존

실제 bag 장애물 점이 아닌 합성 선형 점 24개입니다. 이전 지면 높이 Z=-1.5m 위에 놓여 있습니다. 현재 입력은 30점 미만이고 일직선이어서 새 평면을 추정할 수 없습니다. 24점은 지면일 수도 있으며 장애물 정답은 없습니다. 보존을 객체 검출 개선으로 판단하면 안 됩니다.

회전 0→10°는 context 값입니다. 이 시험은 이미 필터 좌표에 있는 점을 넣으며, 실제 raw scan을 회전한 시험은 아닙니다. 실제 PCL 지면 함수의 결과는 이전 fallback 0점 / common 보존 24점입니다.

2. 신규 분류 차이 11개 관측

주 bag의 동일 LiDAR source stamp를 비교합니다. 10개는 car→unknown, 1개는 unknown→car이며 동일 객체의 연속 관측이 포함됩니다. 대상 박스는 두 실행에서 같은 원본 영상에 투영했습니다. 아래 확대 및 base_link 평면도도 함께 비교하세요.

분류 차이는 객체 삭제와 다릅니다. 같은 관측에 실측 3D 박스가 있어도 확인 카운터·이력 때문에 unknown일 수 있습니다. 실제 차량 여부는 원본 영상으로 검토해야 합니다. 상호 유일 최근접 0.25m 대응은 독립 GT가 아닙니다.

3. 속도 튐: 횟수와 변화량

같은 추적 ID의 내부 CA 상대속도 벡터가 직전 상태보다 2m/s 초과 변한 이벤트입니다. 실제 속도·가속도 또는 속도 오차가 아닙니다. 초기화·군집 중심 변화·오연결·자세 변화·실제 운동이 섞일 수 있습니다.
