# 2026-10-22 장시간 LiDAR 추적 ID와 빈 Planner 입력

전체 시나리오 검증 중 사용자가 신호 통과 후 저속·정지 반복과 AVOID 미선택을
지적하여, 신호 사건과 인지 입력을 별도로 추적했다. 이 결함은 WSL 시계나
황색 행동 규칙 변경과 구분한다. 커밋·푸시는 수행하지 않았다.

## 실제 확인

- `full-scene-natural-03`의 `/last_lidar` 3,216프레임이 모두 빈 배열이었고
  `/planning/objects` 3,181프레임도 모두 비었다. AVOID 대상은 전 구간 -1이었다.
- 같은 시점의 원본 LiDAR에는 앞 Niro 위치의 비지면 점 100여 개가 있다.
  정지 상태에서 동일 모델·좌표를 재현한 `held-avoid-diagnostic/held.bag`는
  원본·ROI·지면 제거·군집 중심·최종 발행과 motion debug를 함께 기록한다.
  지면 제거 후 차량 위치의 점 105개와 해당 군집 중심이 확인됐다.
- `/lidar_tracking_markers`에는 정상 unknown/static_obstacle 추적 ID
  35,578~35,617이 표시되지만, `/lidar/motion_debug`의 공용 변환 raw 수량은 0이다.
- `MakePlannerObjects`가 ID >= int16 최대값(32,767)을 제외한다.
  현재 `Msg/TrackedObject.id`, `asmc_msgs/TrackedObject.id`, native PlannerObject는
  모두 int32다. 반면 과거 UDP 슬롯만 int16이며 자체 범위 검사를 이미 한다.

따라서 추적·군집·도로 필터 앞에서 사라진 것이 아니라, 과거 UDP 제약이
공용 ROS 변환에 적용되어 장시간 실행 중 모든 큰 ID가 탈락했다.

## 변경과 검증 범위

공용 변환의 int16 상한만 제거한다. ROS 메시지와 ID를 그대로 보존하며
wrap·truncation·재번호 부여를 하지 않는다. 미관측·음수 ID·noise·비정상
geometry 거부는 유지한다. UDP 전용 sender의 기존 범위 검사는 유지한다.

회귀 시험은 32,766·32,767·실제 관측 35,604·int32 최대값 근처의 정상 입력,
최대 객체 수가 1인 프레임의 ID 보존, invalid/missed/noise 배제를 확인한다.
Main의 회귀 시험 3개와 전체 빌드가 통과했다. 기존 Main launch를 정확한
프로세스 식별로 종료하고 같은 인자로 다시 시작했다. 다른 ROS 기본 노드는
유지했으며 Main의 새 실행 상태를 별도 owner 기록으로 보존했다.

수정 후 정지 상태 진단에서 기존 도로 내 Niro와 prop2가 Planner 입력까지
전달되는 것을 확인했다. 이어 `post-idfix-091-obstacle-01` 회차는 prop2를
옮기지 않고 C091 신호 구간을 실제 주행했다. 닫힌 bag의 공용 LiDAR 객체는
486프레임 모두 비어 있지 않았고 Planner 객체는 447프레임 중 311프레임이
비어 있지 않았다. AVOID 요청 208건, 유효하고 수락된 AVOID 계획 317건이
기록됐다. 독립 실제 평가에서 C091은 초록 통과 1회, 신호 위반·충돌·도로
이탈·관측 공백 0건으로 해당 국소 회차가 통과했다. 마지막 Controller 상태의
failure_mask도 0이다. bag SHA는
`81ecb4397d7bff662c2f5b642d4b1b784fc910eff20695bddb3d2c4992d07c4d`이다.
이 결과는 한 신호 구간의 객체 출판·AVOID·제동 해제 확인이며 전체 장면의
인지 재현율이나 전체 경로 반복 합격으로 확대하지 않는다.

## 신호 문제와의 구분

첫 신호 C077/A682는 `EXITED` 후 해제되고 다음 신호 C091/A807로 전환됐다.
중단 위치는 C091 물리선의 후륜축 근처이며, 정상 진입으로 확정되지 않은
사건이 RECOVERY_BRAKE에 남았다. 원본 extra 영상은 이 위치에서 신호를
포함하지 않는다. 첫 신호가 영구적으로 남았다고 결론내리지 않는다.

이 현상은 별도로 확인한다. 정상 통과가 확인된 신호는 정책 회귀 시험에서
`EXITED` 뒤 새 제동 요구를 만들지 않았다. 국소 재주행도 현재 C091 신호를
정상 통과하며 끝났지만, 이전의 C091 영상 음영·진입 시점 불확실 사례가
자연 신호 반복에서 재현되는지는 계속 검증한다. 안전한 신호 해제와 AVOID
경로 인계를 검증하되,
초과·불확실 사건 기록을 지우거나 실제 신호 색상을 운영 허가에 넣지 않는다.
빈 인지 입력으로 실행한 이전 전체 주행은 인지·장애물 회피 검증의 근거로
사용하지 않는다. 기존 실제 신호·충돌·도로 관측 결과는 해당 조건의 기록으로
보존한다.
