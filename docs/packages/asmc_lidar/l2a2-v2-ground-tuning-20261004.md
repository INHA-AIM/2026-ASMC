# 객체 보존 우선 지면 설정 조정 결과

2026-10-04 L2-A2-V2. 동기 1,439프레임과 raw 4,048프레임 전수 채점을 완료했다.
**각 자료에서 객체 보존과 잔여 구조 조건을 모두 통과한 단일 변수 설정은
없었다. 12개 튜닝 설정은 모두 미채택이며 운영 입력과 기본값은 교체하지 않는다.**
기존 [V1 분석](l2a2-v1-live-ground-review-20261004.md)의 상세 근거는 보존한다.

## 고정 조건과 변경 경계

기준은 `3d43ca7`의 V1이고 손재호 지면 소스는 `6435af1`이다. 같은 ROI,
10cm voxel, pitch 보정, 이미 도착한 과거 IMU 선택을 유지했다.
Patchwork++ 고정 높이1.80m·RNR OFF·25cm 보호, linefit 높이1.78m·90×60은
변경하지 않았다. 원본점 계보·intensity·ns stamp·rear-axle base_link 계약도
유지한다. GT는 채점에만 사용하며 군집·OBB·추적은 실행하지 않았다.

비교는 V1, linefit 처리 누락 수정만, 방법별 6개 단일 변수 설정의 14개 profile이다.
각 linefit 설정은 누락 수정도 포함한다. 수정 효과와 튜닝 효과를 혼합하지 않도록
`lf_covered`를 별도 대조군으로 둔다. 모든 설정과 재실행 방법은
[실험 도구](../../../tools/lidar/ground_tuning/README.md)에 있다.

`linefit_cover_all`은 마지막 sector와 점까지 정확히 한 번 처리하도록 한다.
V1의 90 sector/4 thread에서는 88·89번 sector가 미처리되고 점 수도 4로
나누어떨어지지 않으면 끝부분이 미처리될 수 있었다. 삽입 순서 안정화는 그대로다.
external과 vendor 알고리즘 원본을 수정하지 않고 SHA를 검사한 build 파생본에
선택적으로 반영했다. `comparison_config`를 생략하면 V1 동작을 유지한다.

## 잔여점의 직접 분류 사유

동기 V1 Patchwork++에 남은 아스팔트182,004점 중 직접 기록된 사유는
near patch heading 거부81,695점, TGR 거부65,044점, patch 점 부족28,991점이다.
25cm 보호로 되살린 점은4,310점이고 최종 평면 거리 초과는51점이다.
비트는 중복될 수 있다. 예를 들어 TGR 후보와 TGR 거부를 합산하지 않는다.

따라서 이번 자료의 잔여를 모두 높이 보호 또는 단순 거리 임계값 탓으로
설명할 수 없다. 거리 파라미터는 평면 피팅과 적응 상태에도 간접 영향을 주므로
위 숫자가 해당 파라미터 변경의 전체 인과 기여량이라는 뜻도 아니다.

linefit에 남은 아스팔트78,773점 중 이웃 탐색 이후에도 유효 선이 없는 점은
70,425점이다. 허용 거리를 넓히는 것과 유효한 선의 지지를 확보하는 것은
다른 문제다. 이웃 탐색을 넓히면 일부 노면은 지워지지만 객체 하부도 손실됐다.
VLP16 희소 관측의 평면·선 지지 조건을 다음 분석 대상으로 남긴다.
이것이 모든 실패 원인이라는 단정이나 새로운 알고리즘 채택은 아니다.

raw에서도 PP 잔여 아스팔트458,601점 중 heading 거부164,958점,
TGR 거부216,186점, patch 점 부족74,722점이었다. 보호 복원은323점,
직접 평면 거리 초과는221점이다. LF 잔여260,739점 중 이웃 탐색 이후에도
유효 선이 없는 점은244,684점, 거리 초과는16,055점이었다.
**거리 허용치만 늘리는 것보다 지역 평면·선의 지지 여부를 먼저 확인할 근거**다.
GT는 이 사유별 채점에만 쓰고 알고리즘 판단에 넣지 않았다.

## IMU 보조 자료와 실시간 확인

무라벨 수동주행644스캔도 같은14설정으로 처리했다. pitch 범위는
-1.207~2.311도이며 장면별 자세나 높이를 GT로 보정하지 않았다.
점 수·보호 복원점·비용은 `manual_summary.json`에 남겼다. 지면 또는
객체 정확도 GT로 해석하지 않는다. 기존 경사 민감 장면 `manual_all_000365`를
포함해 동일 입력 BEV·측면 그림을 보존한다.

실시간70초 점검 두 번에서 기존 bridge는 그대로 유지했고, 생성한 리뷰 노드만
종료했다. 다른 offline 평가와 동시에 실행한 계측이므로 고립된 성능 순위가 아니다.

| 설정 | 입력/처리 Hz | 내부 큐 누락 | stale IMU | 수신→발행 p50/p95/p99 |
|---|---:|---:|---:|---:|
| LF 누락 수정만, 세 방법 계산 | 8.98 / 8.93 | 0 | 4 | 20.47 / 27.20 / 32.27ms |
| PP 거리8cm, 세 방법 계산 | 9.78 / 9.77 | 0 | 1 | 21.31 / 24.08 / 26.88ms |

첫 점검에서 gRPC 제한 저속 이동1.495m, 최고1.254m/s를 확인하고 위치·gear·
제어 모드를 복구했다. 전 구간 연속 주행이나 실제15Hz 수락시험은 아니다.
수신→발행은 센서 광선 측정·네트워크 이전 지연을 포함하지 않는다.

첫 실행의 공통 준비(수평화 포함)는 p50/p95/p99=18.09/24.64/29.76ms,
지면 분할은 재호0.424/0.507/0.568ms, PP0.458/0.707/0.759ms,
LF0.688/0.830/0.924ms였다. 방법별 분할만 보고 전체 지연을 추정하지 않는다.
오프라인의 수평화·복사·분할·복원 합계는 계측하지 않은 bookkeeping을 제외하므로
`accounted_stage_sum_ms`로 명시했다. 초기에 `total_core_ms`라고 명명한 요약은
원본 백업을 보존하고 이름과 설명을 정정했다. 실제 전체 처리시간은 ROS의
`compute_ms`, 수신부터 발행까지는 별도 계측값이며 서로 대체하지 않는다.

## 검증과 재현 자료

- Noetic Release 빌드와 CTest5개, 지표 합성5개, 신규 채점 합성2개 통과.
- 기존 오프라인 입력6조건, 고정 소스·입력SHA12개 검사 통과.
- 기존 Python 회귀63개는 Git 연결이 유효한 호스트에서 통과. 컨테이너에서
  실행한 같은 묶음은 host gitdir 미마운트로 provenance 시험1개가 실패하여
  호스트에서 재검증했다. 이를 알고리즘 통과로 숨기지 않는다.
- 동기1,439/raw4,048의 V1 마스크·계보·stamp 정확 재현.
- 새 채점기의 V1 결과도 기존 요약의612개 계수 필드와 모든 이웃 그래프 지표가
  각각의 자료에서 정확히 일치함.
- 14설정 각각 독립 인스턴스 두 개로 전체 시퀀스 반복 시 분류·보호 전 결과·
  점별 사유·피팅 사건이 동일함. 실행시간은 결정성 비교에서 제외.
- LF 누락 수정과 PP 거리8cm 각각 ROS 실측12프레임, 15개 점군의 좌표·
  원본 인덱스·intensity·stamp 일치 및 예외7조건·공통 큐 초과 검사 통과.

산출물은 `$ASMC_DATA/lidar_assessment/20261004_ground_v2`에 있다.
`sync`·`raw`는 설정별 mask·진단·실행 manifest, `*_metrics`는 요약·관측별
진단·개별 회귀, `figures`는 같은 입력의 BEV/측면, `*_repeat.log`는 반복 검증이다.
원본 bag과 센서셋은 수정하거나 복사하지 않는다.

[고정 manifest](../../../config/baselines/lidar_l2a2_v2_ground_tuning_20261004.json)는
입력·소스·설정·실행 바이너리·결과의 SHA를 연결한다. 알고리즘 파일은 `848587d`
동결 뒤 변경하지 않았음을 검사하며, 이후 검증 도구와 보고서 추가는 별도 파일 SHA로
기록한다. 원본점 파일을 포함한 V1 입력 inventory도 재해시해 검증한다.

## 다음 검토와 되돌리기

객체 보존을 희생하지 않는다는 이번 기준은 유지한다. 다음에는 PP의 지역
평면 heading·TGR 거부와 linefit 유효 선 부재를 실제 관측 지지점으로 분석하고,
필요하다면 지지 부족을 처리하는 구조 개선을 별도 단위로 설계한다.
고정 높이 보호의 경사 대응도 독립 문제로 유지한다. 군집화로 자동 진행하지 않는다.

기존 명령에서 `comparison_config`를 생략하면 V1이다. 운영 토픽·메시지 MD5·
판제·HD맵·센서 설정은 이번 커밋에서 바꾸지 않았고 푸시·PR도 하지 않는다.
