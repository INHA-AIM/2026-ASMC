# 플래너 공통 HD map — v7

모든 Frenet 모드와 고주로 참조선은 main의 공식 v7 벡터·격자 제품을 사용한다.
`avoid_hd_map`이라는 설정 이름은 호환성을 위해 유지한다.

- 정본: `src/asmc_hd_map/config/kcity2025_compact_drivable_map.json`
- build: `kcity2025_reviewed_high_speed_adjacent_drivable_v7`
- `drivable.json`: 정본과 바이트까지 같은 벡터 제품.
- `drivable_grid.rle`: 공식 NPZ의 모든 free cell을 그대로 내보낸 0.2 m 격자.
- `lines.json`: 기존 검토 완료 도색·정지선 자료를 유지한다.

```bash
python3 tools/planning/sync_hd_map.py --check
python3 tools/planning/sync_hd_map.py
```

공식 제품은 수정하지 않는다. 고주로 차로 참조선의 polygon reader는 원본의
정확한 A-B-A 왕복 선분만 제거하고, 같은 정점에서 닫힌 내부 loop는 hole로
보존한 뒤 Boost validity를 다시 검사한다. 좌표 이동·buffer·면적 기반 틈
메우기는 하지 않으며 일반 자기 교차는 거부한다. 실제 v7 제품과 역순 로딩,
좁은 내부 비주행 영역, 외부 점과 차체 포함 검사는 회귀 테스트에서 확인한다.

영역 확대는 이전과 같은 후보 선택이나 폐루프 주행을 보장하지 않는다.
차체 충돌·곡률·가감속·조향 제한과 각 모드의 도로 제약은 별도로 유지한다.
고정 입력 테스트 이후 MORAI/MPC 폐루프 주행으로 확인해야 한다.

AVOID의 실선 접촉은 고정 2.5초 제한 대신 실제 접촉 이력과 후보의 접촉 시간에
따른 비용으로 평가한다. 기본 후보 비교에서는 무접촉 후보를 우선하고, 정지
종단이 도색 위에 있으면 최소 5초 동안 계속 접촉하는 비용을 계산한다. 이 5초는
비용 비교 구간이며 접촉 허용 기한이나 실행 궤적의 연장이 아니다. 도로 영역과
실제 장애물 충돌 검사는 그대로 적용한다.

저속 KEEP·일반 STOP 출발에서 이미 차체 일부가 영역 밖에 있는 경우에는 명시적인
부분 이탈 복구 정책을 적용한다. 계획 첫 입력 또는 KEEP·일반 STOP 모드로 전환할
때의 기존 저속 범위에서만 진입을 허용하며, 일반 감속 도중에는 새로 켜지지 않는다.
35 cm 깊이·10% 차체 샘플·6 m 거리·5초 복구 기한으로 후보를 탈락시키지 않는다.
대신 복구 시간과 이탈 깊이·샘플 비율의 시간 적분을 비용으로 평가한다. 차체가
격자와 완전히 분리되는 후보는 거부하고, 실제 위치·헤딩에서 시작해 완전히 복귀한
뒤 확장 차체가 영역 안에서 0.5 m 진행하는 구간까지 검사한다. 이 판정은 차체와
지도 격자에 대한 검사이며 심판의 개별 바퀴 판정을 대체하지 않는다.

STOP 복구는 기존 거리 기반 정지 속도 계획과 목표점을 유지하고, 기존 d(s) 경로
생성기를 사용한다. 복구 검사에는 같은 정지 프로파일을 0속도 종단까지 확장해
사용하므로 5초 horizon이 복구 기한으로 재도입되지 않는다. 일반 STOP의 horizon과
공용 Cartesian 헤딩 변환은 변경하지 않는다. 복귀가 확인되면 복구 상태를 종료하고
정상 검사를 적용한다. 이미 영역 안에서 출발하는 주행에는 새 이탈 권한을 부여하지
않고, AVOID·MERGE의 기존 복구 한도와 회전교차로 대기 정책도 유지한다.

지도·LiDAR 필터·속도 상한과 충돌·곡률·가감속·Controller 조향 한계는 유지한다.
Planner 상태와 내부 정책 인자가 바뀌므로 실행 파일과 연결 라이브러리는 함께
다시 빌드해야 한다. 오프라인 초기 입력 재생과 이상적인 추종 재계획 검사는 실제
MORAI/MPC 폐루프 주행 검증을 대체하지 않는다.
