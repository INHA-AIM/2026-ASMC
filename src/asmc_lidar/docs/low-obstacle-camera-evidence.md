# 저상 장애물의 카메라 임시 근거

`experimental.tunnel_filter.low_obstacle_evidence`는 지면 제거 후에도 남은 점의 제한된 객체 근거다. 단순히 YOLO 사각형 안에 있다는 이유만으로 모든 배경을 보호하지 않는다. 일반 3뷰 융합의 분류 확정과 별개이며 확정 클래스나 GT를 만들지 않는다.

전방의 원래 클래스·정확한 이미지 크기/보정·현재 receiver epoch를 확인한다. 미래 이미지를 거부하고, 다른 시각의 영상은 검증된 움직임 보정이 있어야 하며 최대150ms로 제한한다. 벽/천장을 깊이 경쟁에서 무시하지 않고, 확인한 지면보다 충분히 높은 현재 연결 성분만 사용한다.

이 근거는 제한된 군집 중심 sensor Z 판정과 저상 ground-residual OBB 판정에만 예외를 줄 수 있다. 원시점 ROI, 점 단위 지면 제거, 벽·천장 거부는 그대로 유지한다. 지면으로 이미 제거한 점은 복원하지 않는다. 확인하지 않은 원본 군집의 나머지 점도 객체로 승격하지 않는다.

기존 추적기의 잠깐의 예측은 원래 근거 시각을 갱신하지 않는200ms/최대2누락 상한을 따른다. 예측은 현재 실측이 아니며 새 클래스 확정이나 실제 점 생성에 사용하지 않는다. 근거 중단·epoch 교체·만료는 기존 필터 정책으로 돌아간다.

활성화와 별도 저상 튜닝은 [정제 프로필 생성](camera-point-refinement.md#프로필-생성)을 사용한다. 기본 main 튜닝을 바꿀 때는 최소점·지면 폭 변경의 영향과 로직 변경의 영향을 분리해 검증해야 한다. Cargo는 현재 모델의 원래 클래스 `box`, steel은 `steel_barricade`다. 정적인 상위 그룹 전체에 예외를 주지 않는다.
